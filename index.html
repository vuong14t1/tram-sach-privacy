Tram Sach Uploader

A private upload tool for the YouTube channel Trạm Sách Cuối Ngày (@tramsachcuoingay).

YouTube This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy.

What it does

  • Uploads the channel owner's own finished videos (videos.insert).
  • Sets title, description, tags and custom thumbnail (thumbnails.set).
  • Adds each video to the owner's playlist "Sách cho đêm nay" (playlistItems.insert).

It is a command-line script that runs only on the owner's computer, used by one person on one channel. It is not offered to the public and does not access anyone else's data.
